# Max Messenger Mod by Red Motion Studio

В этом репозитории находится декомпилированный код мессенджера Макс. Я его модифицировал, чтобы очистить от избыточного контроля, трекеров и аналитики.

### Дисклеймер
Код этого приложения буквально пропитан трекерами на уровне Smali-инструкций. Это не просто отдельные функции, а часть самой логики. Если вырезать абсолютно все, приложение перестанет работать. Я не рекомендую использовать любые моды Макса для передачи по-настоящему конфиденциальных данных.

---

### Список изменений


Сетевая изоляция и трекеры
Основной эндпоинт sdk-api.apptracer.ru перенаправлен на 127.0.0.1. Теперь серверы аналитики не получают отчеты. 
- Полностью удален VK Analytics.
- Модули AppsFlyer и Mytracker ослеплены и больше не шлют JSON-отчеты об установке.
- Инициализация Firebase и сбор AppInstanceId заглушены.

Приватность и доступ
- Удалены права на точное местоположение (ACCESS_FINE_LOCATION), рекламный ID и состояние Wi-Fi.
- Методы получения данных SIM-карты и IMEI в коде заменены на ответ UNKNOWN.
- Вырезан сервис фоновой слежки MediaProjectionService (one.me), который мог использоваться для скрытого захвата экрана или камеры.

Системная часть
- Отключен автозапуск трейсера при включении телефона (ru.ok.tracer.startup).
- Приложение переподписано дебаг-ключом для изоляции от оригинальной экосистемы ВК.

Примечание: Я оставил некоторые редиректы на сторонние сервисы, чтобы не ломать логику приложения. Пользуйтесь на свой страх и риск.
